# LifePath Vietnam

LifePath Vietnam is a working prototype for Data for Life 2026. It turns a
citizen's life event into a guided public-service journey with relevant
benefits, ordered procedures, document readiness, deadlines, and case
tracking.

## Demo

This repository contains a static demo in `dist/`. GitHub Pages is configured
to publish that directory through the included workflow.

## Scope

The prototype uses simulated data and deterministic eligibility rules. It does
not connect to VNeID or production government systems.
